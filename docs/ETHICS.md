# 伦理与合规边界

Self-Awakening 的目标是提高 AI 服务透明度，而不是帮助绕过服务条款、盗用接口或制造恶意竞争。

## 鼓励的使用方式

- 用户审计自己购买或被授权使用的 AI 服务
- 开发者验证路由层是否按声明工作
- 研究者比较不同模型的黑盒行为差异
- 平台方主动发布可复现透明度报告

## 不鼓励的使用方式

- 未经授权批量压测第三方接口
- 绕过鉴权、费用、地域限制或风控系统
- 将第三方 API 未授权包装成转售服务
- 将概率推断包装成确定性指控
- 使用泄漏题库制造虚假评测结果

## 报告原则

- 给出证据，不给出夸张结论。
- 给出置信等级，不假装绝对确定。
- 保留运行参数，方便复现。
- 对供应商、用户和贡献者都保持可纠错空间。

## 隐私原则

- 默认不保存 API Key。
- 默认不上传运行结果。
- 运行结果可能包含模型回答中的敏感内容，公开分享前应人工审查。
- 探针设计应避免诱导用户输入私人信息。
