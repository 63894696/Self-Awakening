## What you may do without permission

- Use the code under AGPL-3.0-or-later.
- State factually that your work "uses Self-Awakening" or "is derived from
  Self-Awakening", as long as the statement is true and does not imply
  endorsement.
- Cite the project in papers, articles, reviews, tutorials, bug reports, and
  talks.
- Keep the project name in a fork's `NOTICE` or `README` attribution section.

## What requires permission

- Using the name or a confusingly similar name as the name of your product,
  service, company, domain, app-store listing, or social account.
- Using the name or logo in a way that suggests the project endorses, sponsors,
  or maintains your product.
- Registering a trademark, domain, or organization name containing
  "Self-Awakening" or "自我觉醒".

## Forks

A fork may keep the name for attribution but must make clear that it is a
modified version, for example:

> This is a modified version of Self-Awakening. It is not endorsed by the
> Self-Awakening maintainers.

## Reporting misuse

Open an issue in this repository with the relevant links. Good-faith academic and
journalistic references are never treated as misuse.
